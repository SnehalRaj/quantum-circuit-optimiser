# Project instructions

Use short, clear sentences. Keep each scientific claim tied to its evidence.
Read CONTRIBUTING.md and docs/DESIGN.md before changes to search or evaluation.
Preserve upstream source, licenses, notices, and attribution.

Keep candidate construction separate from the fixed checker.
Shared rewrites need implementations at both circuit widths.
Record missing mappings for full-width family settings.
Check output coordinates, phase, scratch, and addend preservation.
Freeze finalists before a fresh audit. Preserve inputs and confidence allowances on resume.
Retain failed proposals, failed calls, and unknown usage.
Keep measured gains distinct from inherited gains and future work.

Use focused tests for each change. Run the documented checks before release.
Keep credentials, local paths, generated circuits, and build files outside tracked files.
Run the sharing audit before publishing new evidence.
Cite this repository and the relevant upstream work when you use their results.
